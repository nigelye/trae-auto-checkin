# TRAE 每日自动签到

> 自动完成 TRAE 桌面版 / 网页版每日签到，领取积分（免费用户每天150积分，会员用户每天200积分）

## 📖 工作思路

### 技术原理

TRAE 的签到功能通过后端 API 实现，本项目通过模拟 API 请求来完成自动签到。

**核心 API 接口：**

| 接口 | 方法 | 说明 |
|------|------|------|
| `https://api.trae.cn/trae/api/v2/ug/checkin_credits/status` | POST | 检查签到状态 |
| `https://api.trae.cn/trae/api/v2/ug/checkin_credits/claim` | POST | 领取签到积分 |

**认证方式：** Bearer Token（从浏览器或客户端登录态中获取）

### 设计思路

1. **轻量级**：仅依赖 `requests` 库，无需复杂的浏览器自动化
2. **可靠**：直接调用官方 API，不受页面 UI 变化影响
3. **安全**：Token 仅保存在本地，不上传任何服务器
4. **易用**：提供图形化的任务计划设置脚本，一键配置定时任务

## 🚀 使用方法

### 前置要求

- Windows 操作系统
- Python 3.8+（需安装 `requests` 库）
- 已注册并登录 TRAE 账号

### 第一步：获取 access_token

1. 打开浏览器，访问 [https://www.trae.cn/work](https://www.trae.cn/work) 并登录
2. 按 `F12` 打开开发者工具
3. 切换到 **Network（网络）** 标签
4. 在 TRAE 页面点击头像 → 点击「签到」
5. 在开发者工具中找到 `checkin_credits` 相关的请求
6. 点击该请求，在 **Headers（请求头）** 中找到 `Authorization`
7. 复制 `Bearer ` 后面的一长串字符（这就是 access_token）

### 第二步：配置 Token

打开 `checkin_config.json` 文件，将内容修改为：

```json
{
  "access_token": "你的access_token"
}
```

### 第三步：测试运行

双击 `run_checkin.bat`，查看输出是否成功。

成功输出示例：
```
[2026-09-15 09:00:00] ==================================================
[2026-09-15 09:00:00] 开始执行 TRAE 每日签到任务
[2026-09-15 09:00:00] 正在检查签到状态...
[2026-09-15 09:00:01] 今日未签到，正在领取积分...
[2026-09-15 09:00:02] 签到成功！获得 200 积分
[2026-09-15 09:00:02] 签到任务结束
[2026-09-15 09:00:02] ==================================================
```

### 第四步：设置定时任务

#### 方式一：使用设置脚本（推荐）

1. **右键点击** `setup_task.ps1`
2. 选择「**使用 PowerShell 运行**」
3. 按照提示操作即可

#### 方式二：手动设置

1. 按下 `Win + R`，输入 `taskschd.msc` 回车
2. 点击右侧「创建基本任务」
3. 名称填写：`TRAE每日签到`，点击下一步
4. 触发器选择：「每天」，点击下一步
5. 设置开始时间为 `9:00:00`，点击下一步
6. 操作选择：「启动程序」，点击下一步
7. 程序或脚本：浏览并选择 `run_checkin_hidden.vbs`
8. 点击下一步 → 完成

## ❓ 常见问题

### Q: Token 会过期吗？
A: 会的，通常有效期为数天到数周。如果签到失败，重新获取一次 token 即可。

### Q: 如何查看签到记录？
A: 查看 `checkin.log` 文件，里面有每次签到的详细日志。

### Q: 如何修改签到时间？
A: 打开任务计划程序，找到「TRAE每日签到」任务，右键 → 属性 → 触发器 → 编辑。

### Q: 如何取消定时任务？
A: 打开任务计划程序，找到「TRAE每日签到」任务，右键 → 删除。

### Q: 签到失败怎么办？
A:
1. 检查网络连接是否正常
2. 查看 `checkin.log` 中的错误信息
3. 如果提示 token 无效，重新获取 token 并更新配置文件
4. 确保你的 TRAE 账号状态正常

### Q: 支持 macOS / Linux 吗？
A: 目前脚本本身跨平台（Python），但定时任务设置脚本仅支持 Windows。macOS/Linux 用户可使用 cron 来设置定时任务。
