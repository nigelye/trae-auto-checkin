## ✨ 特性

- **零配置自动提取 Token**：自动从 TRAE 桌面版本地存储解密提取登录态，无需手动抓包
- **AES-128-CBC 解密**：逆向官方加密算法，安全可靠
- **轻量级**：直接调用官方 API，无需浏览器自动化
- **定时签到**：支持 Windows 任务计划程序，每天自动签到
- **日志记录**：完整的签到日志，便于排查问题

## 📖 工作原理

### 技术原理

TRAE 桌面版将登录态加密存储在本地 `storage.json` 文件中。本脚本通过 AES-128-CBC 解密算法提取 accessToken，然后调用官方签到 API 完成每日签到。

**核心 API 接口：**

| 接口 | 方法 | 说明 |
|------|------|------|
| `https://api.trae.cn/trae/api/v2/ug/checkin_credits/status` | POST | 检查签到状态 |
| `https://api.trae.cn/trae/api/v2/ug/checkin_credits/claim` | POST | 领取签到积分 |

**认证方式：** `Cloud-IDE-JWT` Token（从桌面版本地存储自动解密获取）

### 解密流程

```
storage.json → base64解码 → 提取随机Key
    → SHA-512(Key) → 与固定密钥XOR结果拼接
    → 再次SHA-512 → 前16字节为AES Key，后16字节为IV
    → AES-128-CBC解密 → 跳过HMAC → 得到JSON认证数据
```

## 🚀 使用方法

### 前置要求

- Windows 操作系统
- Python 3.8+
- **已安装并登录 TRAE 桌面版**
- 安装依赖：`pip install -r requirements.txt`

### 快速开始（3步）

#### 第一步：安装依赖

```bash
pip install -r requirements.txt
```

#### 第二步：测试运行

双击 `run_checkin.bat`，查看输出是否成功。

成功输出示例：

#### 第三步：设置定时任务

##### 方式一：使用设置脚本（推荐）

1. **右键点击** `setup_task.ps1`
2. 选择「**使用 PowerShell 运行**」
3. 按照提示操作即可

##### 方式二：手动设置

1. 按下 `Win + R`，输入 `taskschd.msc` 回车
2. 点击右侧「创建基本任务」
3. 名称填写：`TRAE每日签到`，点击下一步
4. 触发器选择：「每天」，点击下一步
5. 设置开始时间为 `9:00:00`，点击下一步
6. 操作选择：「启动程序」，点击下一步
7. 程序或脚本：浏览并选择 `run_checkin_hidden.vbs`
8. 点击下一步 → 完成

## ❓ 常见问题

### Q: 为什么能自动获取 Token？安全吗？
A: TRAE 桌面版将登录态加密存储在本地。脚本使用与官方相同的 AES-128-CBC 算法在本地解密，**所有操作都在你的电脑上完成，不会上传任何数据到第三方服务器**。

### Q: Token 会过期吗？
A: 会的。但由于脚本每次运行时都从桌面版重新读取最新的登录态，只要你保持桌面版登录状态，脚本就会一直有效。如果你退出了桌面版登录，签到才会失败。

### Q: 如何查看签到记录？
A: 查看 `checkin.log` 文件，里面有每次签到的详细日志。

### Q: 如何修改签到时间？
A: 打开任务计划程序，找到「TRAE每日签到」任务，右键 → 属性 → 触发器 → 编辑。

### Q: 如何取消定时任务？
A: 打开任务计划程序，找到「TRAE每日签到」任务，右键 → 删除。

### Q: 签到失败怎么办？
A:
1. 检查网络连接是否正常
2. 确保 TRAE 桌面版已登录
3. 查看 `checkin.log` 中的错误信息
4. 如果提示 token 无效，在 TRAE 桌面版中重新登录即可

### Q: 支持 macOS / Linux 吗？
A: 脚本本身跨平台（Python），但自动提取 Token 的功能仅支持 Windows 桌面版。macOS/Linux 用户可手动配置 token 后使用。
